## ▶️ Getting Started — Reproduce It Yourself

1. Clone the repo: `git clone https://github.com/AravindB98/Projects.git`
2. Open any project folder and its notebook in Jupyter: `jupyter notebook`
3. Install that project's imports as prompted (most need only `pandas`, `scikit-learn`, `matplotlib`)
